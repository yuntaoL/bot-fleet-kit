# bot-fleet

Private backup of this bot fleet, created from bot-fleet-template.

- Bots and roles: `fleet.json`
- Rules: `rules/common.md`, `rules/roles/`, fleet overlay `rules/local/`
- Restore: tell a fresh bot "Clone this repo and follow docs/RESTORE.md."
- Update template: `BOT_ROLE=manager scripts/upgrade.sh <version>` (docs/VERSIONING.md)
- Template version: see `VERSION`
